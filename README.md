# HCAK26

## ATLAS - 3D file explorer (Godot 4.7 .NET, Windows)

**Download:** open the [Releases](../../releases) page, download `ATLAS-windows-x64.zip`, unzip it (keep every file together) and run `ATLAS.exe`.
Nothing else needs to be installed. Windows may show a SmartScreen warning because the app is not code-signed: choose *More info* > *Run anyway*.

**Build it yourself:** open `ATLAS/project.godot` in Godot 4.7.2 (.NET), then *Project > Export > Windows Desktop*.
Releases are built automatically by `.github/workflows/build-atlas-windows.yml` whenever a `v*` tag is pushed.
